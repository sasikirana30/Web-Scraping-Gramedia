# Web-Scraping-Gramedia 
--- 

## Deskripsi Project

Project ini bertujuan untuk membangun proses ETL (Extract, Transform, Load) menggunakan data produk dari website Gramedia yang diperoleh melalui teknik web scraping. Data yang berhasil dikumpulkan kemudian dibersihkan dan ditransformasikan menggunakan Python serta Pandas sebelum dimuat ke dalam database PostgreSQL.

--- 
## Objectives
  1. Mengambil data produk dari website retail menggunakan web scraping.
  2. Melakukan pembersihan dan transformasi data menggunakan Pandas.
  3. Menyimpan hasil transformasi ke dalam file CSV.
  4. Membuat database PostgreSQL yang sesuai dengan struktur data.
  5. Memuat data dari CSV ke PostgreSQL menggunakan script SQL.
